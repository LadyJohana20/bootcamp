¡Bienvenido!

Este es un servidor web utilizando Express que sirve un sitio estático con tres páginas: "index.html", "about.html" y "contact.html". Este servidor escucha el puerto 3000 y muestra las páginas correspondientes a las rutas "/index", "/about" y "/contact" respectivamente. Además, maneja adecuadamente los errores 404 y 500.
